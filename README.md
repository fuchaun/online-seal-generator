# 在线印章生成器

一个基于 Vue 3 + Vite 的在线印章生成工具，遵循中国公章标准规范，专注于圆形公章制作。

## 功能特性

- 🔴 **标准红色印章**：固定使用标准公章红色（#DC2626）
- ⭐ **中心五角星**：符合国家标准五角星徽标
- ✏️ **自定义文字**：
  - 环形文字：单位名称从左到右顺时针排列
  - 底部横排：专用章等文字
  - 印章编码：13位数字反弧排列
- 🎯 **灵活配置**：字体大小、展开角度、尺寸、边框宽度均可调节
- 💾 **一键导出**：支持将印章导出为PNG图片
- 📱 **响应式设计**：适配各种屏幕尺寸

## 中国公章标准规范

### 圆形公章规格
- **直径尺寸**：30mm、38mm、40mm、42mm、45mm
- **边框宽度**：
  - φ30mm、φ38mm：1mm
  - φ40mm、φ42mm：1.2mm
  - φ45mm：1.5mm
- **中心徽标**：五角星（直径13-14mm）
- **环形文字**：
  - 字体：宋体
  - 排列：自左向右环形排列
  - 环排角度：250°-270°（本工具默认200°，可调节）
  - 字高：6.5-7.5mm（根据印章大小）
- **底部文字**：横排在五角星下方
- **印章编码**：13位数字，底部反弧排列，Arial字体
- **印章颜色**：标准红色

## 技术栈

- Vue 3 - 渐进式JavaScript框架
- Vite - 下一代前端构建工具
- Tailwind CSS - 实用优先的CSS框架
- HTML5 Canvas - 印章绘制

## 快速开始

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

访问 http://localhost:5173 查看应用

### 构建生产版本

```bash
npm run build
```

### 预览生产构建

```bash
npm run preview
```

## 使用说明

1. **输入单位名称**：在"单位名称"输入框中输入法定名称
2. **配置印章信息**：
   - 印章编码：输入13位数字编码（可选）
   - 印章类型：如"专用章"、"合同专用章"等
3. **调整样式**：
   - 字体大小：调整文字尺寸
   - 环形文字展开角度：控制文字疏密程度（默认200°）
   - 印章直径：调整整体尺寸
   - 边框宽度：调整外圈粗细
4. **实时预览**：右侧会实时显示印章效果
5. **下载印章**：点击"下载印章"按钮保存为PNG图片
